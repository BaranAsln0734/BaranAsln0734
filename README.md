## About

I'm a software developer focused on building practical digital products for real business operations. Through **Safe Dijital**, I work on business software, sector-specific SaaS products, web platforms and automation systems.

My work connects product thinking with engineering: understanding the workflow, modelling the data, building the API and interface, and delivering something people can use.

- **Software engineering:** Full-stack applications, ERP-style systems, REST APIs and SaaS products.
- **Data & AI:** Machine learning, explainable models, analytics and intelligent workflows.
- **Product focus:** Service operations, quotation processes, reporting and industry-specific platforms.
